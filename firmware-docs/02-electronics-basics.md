# 02. 基本電子學（韌體工程師夠用版）

> **一句話**：韌體工程師不需要設計電路，但必須**看得懂電路圖、知道腳位該怎麼設定、量得出問題在硬體還是軟體**。

---

## 1. 電的三個基本量 🟢

| 量 | 單位 | 白話 | 類比水管 |
|---|---|---|---|
| 電壓 V | 伏特（V） | 推動電流的「壓力差」 | 水壓 |
| 電流 I | 安培（A），常用 mA、µA | 每秒流過的電荷量 | 水流量 |
| 電阻 R | 歐姆（Ω） | 阻礙電流的程度 | 水管粗細 |

**歐姆定律**：`V = I × R`
**功率**：`P = V × I`（單位瓦特 W）

範例：LED 接 3.3V GPIO，LED 順向壓降 2.0V，希望電流 10mA：
```
R = (3.3 − 2.0) / 0.01 = 130 Ω → 取標準值 150 Ω
```

## 2. 被動元件 🟢

| 元件 | 功能 | 韌體相關情境 |
|---|---|---|
| **電阻** | 限流、分壓、上拉/下拉 | 分壓電路讓 ADC 量測高電壓（如電池 4.2V → 2.1V） |
| **電容** | 儲能、濾波、去耦 | 每顆 IC 電源腳旁的 100nF **去耦電容**，少了會導致系統不穩、隨機當機 |
| **電感** | 儲能、濾波 | DC-DC 轉換器 |
| **二極體** | 單向導通 | 防反接、保護 |
| **LED** | 發光二極體 | 狀態指示 |

**分壓公式**：`Vout = Vin × R2 / (R1 + R2)`

**RC 時間常數** `τ = R × C`：按鈕的硬體去彈跳、ADC 輸入濾波。

## 3. 主動元件：電晶體 🟢

韌體常見用途：**用 GPIO 控制大電流負載**（馬達、繼電器、LED 燈條）。GPIO 通常只能輸出數 mA～20mA，不能直接驅動馬達。

| 類型 | 說明 |
|---|---|
| **BJT**（NPN/PNP） | 電流控制，常見於簡單開關 |
| **MOSFET**（N-ch/P-ch） | 電壓控制，低損耗，功率開關主流 |

驅動電感性負載（馬達、繼電器）一定要有**飛輪二極體（Flyback Diode）**，否則關斷瞬間的反向高壓會打壞電晶體或 MCU。

## 4. 數位邏輯電位 🟢

| 標準 | 邏輯 1 | 邏輯 0 |
|---|---|---|
| 5V TTL/CMOS | 接近 5V | 接近 0V |
| **3.3V（現代 MCU 主流）** | 接近 3.3V | 接近 0V |
| 1.8V | 低功耗晶片、SoC | |

重點規格（Datasheet 會寫）：
- **VIH / VIL**：輸入被判定為高/低的電壓門檻
- **VOH / VOL**：輸出高/低時的電壓
- **5V Tolerant**：3.3V MCU 的某些腳位可承受 5V 輸入，**不是所有腳都可以**

不同電壓的晶片互連需要**電位轉換器（Level Shifter）**，否則可能燒毀晶片。

## 5. GPIO 電氣模式（面試必考）🟡

### 5.1 輸出模式

| 模式 | 原理 | 用途 |
|---|---|---|
| **推挽（Push-Pull）** | 可主動輸出高與低 | 一般 LED、SPI、UART TX |
| **開汲極（Open-Drain）** | 只能拉低，高電位靠外部上拉電阻 | **I²C**、多裝置共用中斷線、不同電壓轉換 |

開汲極的關鍵特性：**多個裝置可以接在同一條線上**，任一裝置拉低就是低（**Wired-AND**），不會互相短路。推挽輸出如果兩個裝置一高一低就會短路。

### 5.2 輸入模式

| 模式 | 說明 |
|---|---|
| **浮接（Floating / Hi-Z）** | 不接任何電阻，未連接時讀值不穩定（會隨雜訊亂跳） |
| **上拉（Pull-up）** | 透過電阻接到 VCC，未驅動時讀到 1 |
| **下拉（Pull-down）** | 透過電阻接到 GND，未驅動時讀到 0 |
| **類比（Analog）** | 關閉數位輸入電路，給 ADC 使用，也最省電 |

**按鈕典型接法**：按鈕一端接 GND、另一端接 GPIO 並啟用內部上拉 → 平時讀到 1，按下讀到 0（Active Low）。

### 5.3 上拉電阻怎麼選

- 太大（如 100kΩ）：上升時間慢，高速訊號失真，易受雜訊
- 太小（如 100Ω）：拉低時電流大、耗電
- I²C 常用 **4.7kΩ**（100kHz）、**2.2kΩ**（400kHz），依匯流排電容計算
- MCU 內部上拉通常 30～50kΩ，**對 I²C 來說太弱**

## 6. 看懂電路圖（Schematic）🟡

必須認得的符號：電阻、電容、二極體、LED、電晶體、GND、VCC、晶振、連接器、測試點。

讀圖步驟：
1. 找 **MCU 腳位** → 對照 Datasheet 的 Pin Definition / Alternate Function
2. 看每條**網路標籤（Net Label）**：同名代表相連，例如 `I2C1_SCL`
3. 看**電源樹**：哪個 LDO / DC-DC 供給哪顆晶片
4. 看是否有**上拉電阻、濾波電容、保護元件**
5. 記下 **Active High / Active Low**（標示 `nRESET`、`CS#`、`RST_N` 或上橫線代表低電位有效）

## 7. 看懂 Datasheet 與 Reference Manual 🟡

| 文件 | 內容 | 何時看 |
|---|---|---|
| **Datasheet** | 電氣特性、腳位、封裝、時序圖 | 選型、硬體設計、確認電壓與時序 |
| **Reference Manual (RM)** | **每個周邊的暫存器詳細說明** | 寫驅動程式（韌體主要看這份） |
| **Errata** | 晶片已知硬體錯誤與替代方案 | 遇到怪問題時**一定要查** |
| **Application Note (AN)** | 原廠的應用範例 | 學某功能的最佳實踐 |
| **Programming Manual** | CPU 核心指令、NVIC、SysTick | 寫底層、組語、例外處理 |

讀**時序圖（Timing Diagram）**：看 setup time、hold time、clock polarity（SPI 的 CPOL/CPHA）、最小脈衝寬度。

## 8. 時脈（Clock）🟡

| 來源 | 特性 |
|---|---|
| **內部 RC 振盪器（HSI/LSI）** | 免外部元件、啟動快，但精度差（±1%～數 %），會隨溫度飄移 |
| **外部石英晶體（HSE）** | 精度高（±20ppm 等級），**USB、CAN、高速 UART 通常需要** |
| **32.768kHz 晶體（LSE）** | 給 RTC 使用，2¹⁵ Hz 方便除頻成 1 秒 |
| **PLL** | 將基頻倍頻到高頻主時脈（如 8MHz → 168MHz） |

韌體重點：**時脈設定錯誤是 UART 亂碼、計時不準最常見的原因之一**。

## 9. 電源與穩定性 🟡

- **LDO**：線性穩壓，簡單、低雜訊，壓差大時效率差（發熱）
- **DC-DC（Buck/Boost）**：開關式穩壓，效率高，有開關雜訊
- **Brown-out（欠壓）**：電壓下降到一半時 MCU 行為不可預期 → 啟用 **BOR（Brown-Out Reset）**
- **ESD**：靜電可擊穿晶片，對外連接埠要有 TVS 保護
- **接地（GND）**：所有互連設備必須**共地**，否則通訊會失敗（UART 只接 TX/RX 不接 GND 是新手常見錯誤）

## 10. 雜訊與彈跳 🟡

**機械按鈕彈跳（Bounce）**：按下的 5～20ms 內訊號會快速跳動多次。

| 方法 | 說明 |
|---|---|
| 硬體去彈跳 | RC 濾波 + 施密特觸發器 |
| 軟體去彈跳 | 狀態穩定持續 N ms 才確認（見第 22 章手寫題） |

## 面試常問

### Q1. 什麼是上拉 / 下拉電阻？為什麼需要？

當腳位**沒有被主動驅動**時（如按鈕未按下、開汲極輸出放開），輸入會處於浮接狀態，讀值受雜訊影響而亂跳。上拉電阻把它固定到高電位、下拉電阻固定到低電位，確保有**明確的預設狀態**。

### Q2. 推挽與開汲極輸出的差別？I²C 為什麼要用開汲極？

推挽可主動輸出高與低；開汲極只能拉低，高電位靠外部上拉。I²C 是**多主多從共用兩條線**，且需要**時脈延展（Clock Stretching）與仲裁**：任何裝置都可把線拉低，而不會與輸出高電位的裝置短路。若用推挽，一個裝置輸出高、另一個輸出低就會短路。

### Q3. 為什麼每顆 IC 旁邊都有 100nF 電容？

**去耦電容（Decoupling Capacitor）**：數位電路切換時會瞬間抽取大電流，電源線上的電感會造成電壓下陷與雜訊。靠近電源腳的小電容提供局部的瞬時電流、濾除高頻雜訊。少了它，可能出現隨機重開、通訊錯誤等難以追查的問題。

### Q4. 3.3V MCU 要接 5V 感測器，要注意什麼？

1. 查 MCU 腳位是否 **5V Tolerant**
2. 5V 輸出 → 3.3V 輸入：使用電位轉換器或分壓電阻
3. 3.3V 輸出 → 5V 輸入：確認 3.3V 是否高於感測器的 VIH（5V CMOS 的 VIH 常為 3.5V，可能不夠）
4. I²C 可用 MOSFET 雙向電位轉換電路
5. **雙方共地**

### Q5. GPIO 可以直接驅動馬達嗎？

不行。GPIO 只能提供數 mA～20mA，馬達需要數百 mA 以上，且是電感性負載。需透過 **MOSFET / 馬達驅動 IC（H 橋）**，並加上飛輪二極體吸收反電動勢。

### Q6. 如何判斷問題出在硬體還是軟體？

1. **量測**：用示波器 / 邏輯分析儀看實際訊號是否符合預期
2. **縮小範圍**：用最簡單的程式（只翻轉 GPIO）驗證硬體
3. **換板子**：同韌體在另一塊板子是否也有問題
4. **查 Errata**：晶片本身的已知問題
5. 看電源是否穩定（電壓下陷、漣波）

## 過時技術（知道就好）

- **5V 邏輯為主的系統**：現代 MCU 多為 3.3V 或更低，5V 主要存在於舊式工控與 Arduino Uno 生態。
- **穿孔元件（DIP）**：量產多改用表面黏著（SMD），但學習時麵包板仍常用 DIP。

## 本章回顧

- V = I × R；GPIO 只能推小電流
- 推挽 vs 開汲極；I²C 用開汲極 + 上拉
- 浮接輸入會亂跳，要上拉或下拉
- 寫驅動看 Reference Manual，遇怪問題查 Errata
- 互連設備要共地，不同電壓要電位轉換
