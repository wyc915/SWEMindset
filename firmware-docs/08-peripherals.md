# 08. 基本周邊：GPIO、計時器、PWM、ADC、看門狗

> **一句話**：周邊是 MCU 與真實世界互動的手腳。**會用計時器、PWM、ADC**，就能完成大部分控制類產品。

---

## 1. GPIO 🟢

### 1.1 設定步驟（以 STM32 為例）

1. 開啟 GPIO Port 時脈（RCC）
2. 設定模式：輸入 / 輸出 / 複用功能（Alternate Function）/ 類比
3. 設定輸出類型：推挽 / 開汲極
4. 設定上拉 / 下拉
5. 設定速度（Slew Rate：訊號邊緣速度，越快 EMI 越大）

### 1.2 複用功能（Alternate Function）

一個腳位可以當 GPIO，也可以接到 UART TX、SPI SCK、PWM 輸出等內部周邊。**腳位多工（Pin Mux）** 是硬體設計與韌體設定的共同課題，原廠工具（STM32CubeMX、MCUXpresso Config Tools）可視覺化設定。

### 1.3 外部中斷（EXTI）

GPIO 可設定為上升沿 / 下降沿 / 雙邊沿觸發中斷，用於按鈕、感測器的 data-ready 訊號。

## 2. 計時器（Timer）🟢

計時器是**一個隨時脈遞增的計數器**，是 MCU 最萬用的周邊。

```
計時器時脈 ─▶ [預除頻器 PSC] ─▶ [計數器 CNT] ─▶ 等於 [自動重載 ARR] 時 → 更新事件 / 中斷，CNT 歸零
```

**頻率公式**：

```
更新頻率 = 計時器時脈 / ((PSC + 1) × (ARR + 1))

例：時脈 84MHz，要 1kHz 中斷
   PSC = 83   → 計數頻率 1MHz
   ARR = 999  → 1MHz / 1000 = 1kHz
```

### 2.1 計時器功能

| 功能 | 說明 | 用途 |
|---|---|---|
| 基本計時 | 週期性中斷 | 系統 tick、排程 |
| **輸出比較（Output Compare）** | CNT 等於 CCR 時改變腳位 | 產生精準時序 |
| **PWM** | 輸出比較的特例 | 馬達、LED 亮度、蜂鳴器 |
| **輸入捕捉（Input Capture）** | 腳位邊沿發生時記錄 CNT | 量測頻率、脈寬（超音波測距、紅外線解碼） |
| **編碼器模式** | 讀取正交編碼器 | 馬達轉速與位置 |
| 單脈衝 | 觸發後輸出一個脈衝 | — |
| 觸發其他周邊 | 定時觸發 ADC、DMA | 固定取樣率 |

### 2.2 SysTick

Cortex-M 核心內建的 24-bit 遞減計時器，**專門給 RTOS 或系統 tick 使用**（通常 1ms）。所有 Cortex-M 都有，可攜性高。

### 2.3 Delay 的實作

| 方法 | 優缺點 |
|---|---|
| 空迴圈 `for (i...)` | 不準、依最佳化等級而變、浪費 CPU |
| 基於 SysTick 的 `HAL_Delay()` | 毫秒級，阻塞 |
| **DWT Cycle Counter** | M3 以上，CPU 週期級精度，用於 µs delay 與效能量測 |
| RTOS `vTaskDelay()` | 不阻塞其他任務 ✅ |
| 計時器中斷 + 狀態機 | 非阻塞 ✅ |

## 3. PWM（脈衝寬度調變）🟢

```
       ┌──┐     ┌──┐     ┌──┐
       │  │     │  │     │  │
   ────┘  └─────┘  └─────┘  └───
       |←T_on→|
       |←── 週期 T ──→|
   佔空比（Duty Cycle）= T_on / T
```

- **頻率**由 ARR 決定，**佔空比**由 CCR / (ARR+1) 決定
- 用 PWM 的「平均電壓」控制：LED 亮度、直流馬達轉速、加熱器
- 伺服馬達：50Hz、脈寬 1～2ms 對應角度
- **中心對齊 PWM**：馬達控制常用，減少諧波
- **互補輸出 + 死區（Dead Time）**：驅動 H 橋 / 三相逆變器，避免上下管同時導通而短路

頻率選擇：LED 調光 > 1kHz 避免閃爍感；馬達常用 16～20kHz 以上避開人耳聽得到的頻率。

## 4. ADC（類比轉數位）🟡

### 4.1 基本概念

| 名詞 | 說明 |
|---|---|
| **解析度** | 位元數。12-bit ADC 有 4096 階 |
| **參考電壓（Vref）** | 滿刻度對應的電壓 |
| **LSB** | 每一階代表的電壓 = Vref / 2ⁿ |
| **取樣率** | 每秒轉換次數（SPS） |
| **取樣時間** | 內部電容充電時間，訊號源阻抗高時需加長 |

```
電壓 = raw × Vref / (2ⁿ − 1)      （或 / 2ⁿ，依晶片定義）
例：12-bit、3.3V、raw = 2048 → ≈ 1.65V
```

### 4.2 ADC 類型

| 類型 | 特性 | 常見 |
|---|---|---|
| **SAR（逐次逼近）** | 中速中解析度，MCU 內建主流 | 12-bit, 1MSPS |
| **Σ-Δ（Sigma-Delta）** | 高解析度（16～24-bit）、慢 | 秤重、精密量測、音訊 |
| Flash / Pipeline | 極快 | 示波器、通訊 |

### 4.3 取樣定理

**Nyquist**：取樣頻率必須**大於訊號最高頻率的 2 倍**，否則發生**混疊（Aliasing）**。實務上在 ADC 前加**抗混疊低通濾波器**，取樣率取 5～10 倍以上。

### 4.4 提升量測品質

- 硬體：RC 濾波、穩定的參考電壓、類比與數位接地分離
- 軟體：**多次取樣平均**、**移動平均**、**中位數濾波**（去除突波）、**一階 IIR 低通**（`y = y + α(x − y)`）
- 校正：增益與偏移校正、內部參考電壓（VREFINT）補償電源變化
- **Oversampling**：取樣 4ⁿ 次平均後右移 n 位，可提高 n bit 解析度（需有雜訊）

### 4.5 DMA + 計時器觸發

高品質取樣的標準架構：**計時器固定頻率觸發 ADC → DMA 自動搬到緩衝區 → 半滿/全滿中斷時處理**（雙緩衝，見第 10 章），CPU 幾乎不用介入。

## 5. DAC 與其他類比周邊 🟡

- **DAC**：數位轉類比，產生波形、音訊、參考電壓
- **比較器（Comparator）**：類比電壓超過門檻時觸發，用於過電流保護（比 ADC 更快）
- **運算放大器（OPAMP）**：部分 MCU 內建，訊號放大

## 6. RTC（即時時鐘）🟡

- 使用 32.768kHz 晶體，低功耗模式下持續運作
- 可由**備用電池（VBAT）**供電，主電源斷電仍可計時
- 提供鬧鐘中斷，用於定時喚醒
- 時間格式常為 BCD
- 長期準確度需要網路校時（NTP / 手機同步）

## 7. 看門狗（Watchdog）🟡

| 類型 | 時脈 | 特性 | 用途 |
|---|---|---|---|
| **獨立看門狗（IWDG）** | 獨立低速 RC 時脈 | 主時脈失效仍能運作，啟動後**無法關閉** | 防止系統卡死 |
| **視窗看門狗（WWDG）** | 系統時脈 | 必須在**時間視窗內**餵狗，太早或太晚都重置 | 偵測程式執行流程異常（跑太快也算錯） |
| 外部看門狗 IC | 獨立 | 最可靠，安全關鍵系統使用 | 功能安全 |

**正確的餵狗策略（RTOS 系統）**：

```
每個關鍵任務定期回報「我還活著」（設定 bit）
   ↓
監控任務檢查所有任務都回報後才餵狗，並清除旗標
   ↓
任一任務卡住 → 不餵狗 → 系統重置
```

❌ 錯誤做法：在計時器中斷中無條件餵狗 → 主程式卡死時中斷依然運作，看門狗失去作用。

## 8. 其他常見周邊 🟢

| 周邊 | 用途 |
|---|---|
| **CRC 單元** | 硬體計算 CRC32，驗證韌體與封包 |
| **RNG / TRNG** | 真亂數產生器，加密金鑰必備 |
| **加密加速器** | AES、SHA、ECC、PKA |
| **溫度感測器** | 晶片內部溫度 |
| **Unique ID** | 每顆晶片唯一序號，用於裝置識別 |
| **Option Bytes / eFuse / OTP** | 一次性或特殊保護設定（讀保護、開機設定、安全金鑰） |
| **LCD / Display 控制器** | 驅動顯示器（LTDC、DMA2D 圖形加速） |
| **QSPI / OSPI** | 外接 Flash/PSRAM，可記憶體映射 |
| **USB、Ethernet MAC、CAN、SDIO** | 通訊（第 11 章） |

## 面試常問

### Q1. 計時器時脈 72MHz，如何設定產生 1kHz、佔空比 30% 的 PWM？

PSC = 71 → 1MHz；ARR = 999 → 1kHz；CCR = 300 → 30%。（也可 PSC=0、ARR=71999、CCR=21600，解析度更高。）

### Q2. 12-bit ADC、Vref = 3.3V，解析度（LSB）是多少？讀到 1000 代表多少電壓？

LSB = 3.3 / 4096 ≈ **0.806 mV**。1000 × 0.806 ≈ **0.806 V**。

### Q3. 什麼是 Nyquist 取樣定理？違反會怎樣？

取樣頻率需大於訊號最高頻率的兩倍才能重建訊號。違反會發生混疊，高頻訊號被誤判成低頻訊號且無法從數位資料中消除，因此要在取樣前用類比濾波器濾除。

### Q4. 獨立看門狗與視窗看門狗差別？

見第 7 節。IWDG 使用獨立時脈，偵測「卡死」；WWDG 需在時間視窗內餵狗，可額外偵測「執行太快/流程跳過」的異常。

### Q5. 如何量測一個外部訊號的頻率？

1. **輸入捕捉**：記錄兩次上升沿的 CNT 差值，頻率 = 計數頻率 / 差值（適合低頻）
2. **外部計數**：外部訊號作為計時器時脈，固定閘門時間（如 1 秒）計算脈衝數（適合高頻）
3. 處理計數器溢位：無號差值或累計溢位次數

### Q6. 按鈕按一次觸發好幾次中斷，原因與解法？

機械彈跳。解法：硬體 RC + 施密特觸發；軟體在中斷中只記錄時間並暫停中斷，之後在計時器中確認狀態穩定 20ms 以上才判定（或完全用定時輪詢 + 狀態機）。

### Q7. 為什麼不建議用空迴圈做延遲？

時間依編譯器最佳化等級、時脈、Flash wait state 而變；`-O2` 甚至可能整個刪除迴圈；並且佔用 CPU 無法做其他事、增加耗電。應使用計時器、DWT 或 RTOS delay。

## 過時技術（知道就好）

- **軟體模擬 PWM（bit-banging）**：現代 MCU 都有大量硬體 PWM 通道，除非腳位不足，否則不需要。
- **外接 RTC 晶片**：許多 MCU 已內建 RTC，但需要超低耗電或高精度時仍會外接（如 DS3231、RV-3028）。

## 本章回顧

- 用周邊：開時脈 → 設腳位 → 設周邊 → 開中斷
- 計時器頻率 = clk / ((PSC+1)(ARR+1))；PWM 佔空比 = CCR / (ARR+1)
- ADC：解析度、Vref、Nyquist、濾波、DMA + 計時器觸發
- 看門狗要在「確認系統健康」時才餵
